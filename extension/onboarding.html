Two decisions, then you're done

VerifAI checks whether an image was AI-generated or manipulated, and shows you which detector said so. Choose where that runs — it decides whether anything leaves this machine.

1 Where scans run

You can change this any time, per scan mode, in options.

2 Which server

The default is the public instance. Point it at your own deployment, or at http://localhost:3000 if you are running it yourself. Accepting will ask Chrome for permission to reach that one address.

What a verdict actually means

A "real" verdict means the detectors found nothing — not that the file is authentic. Accuracy against generators the models have never seen is not yet measured, and confidence is uncalibrated. Every scan shows which detectors voted, their weights and the model that produced them, so you can judge the number rather than trust it.

A detector that is missing abstains and says so. It is never replaced by a guess.
