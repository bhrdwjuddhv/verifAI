VerifAI options

Where scans run, which server they go to, and what is cached on this machine.

Scan mode

Server

On-device scans use a bundled copy of the server's thresholds and fusion weights. This checks they still match — if the server is retuned and this build is not, an on-device score stops meaning what a deep scan of the same image would.

Cache

Verdicts are cached by the SHA-256 of the file bytes, so re-checking the same image costs nothing and sends nothing. Heatmaps are kept separately under a 3MB budget.

Consent

Auto-scan feeds

Watches Shorts and Reels as you scroll and scores what appears. Off by default, and it only ever runs on-device — auto-uploading whatever you scroll past is not something this extension will do, so switching to deep scan turns it off.

On-device engine

What this machine can actually run. Measured here, not assumed — the answer decides whether an explanation heatmap is instant or takes seconds.
